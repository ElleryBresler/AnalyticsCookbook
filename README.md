# Analytics Cookbook

A collaborative cookbook built by the Applied Data Analytics class.

Everyone contributes one recipe they actually make. By the end of the week we
have a cookbook, and everyone has practiced the exact workflow used to
contribute to software projects on GitHub.


## How to contribute

See `Canvas` for full instructions. In brief:

1. **Fork** this repository to your own GitHub account
2. **Clone** your fork to your computer
3. Create a **branch** named `add-yourlastname`
4. Add your recipe to `recipes/` and add a line to `INDEX.md`
5. **Commit**, **push**, and open a **pull request**

## Structure

```
recipes/       one file per person
INDEX.md       shared table of contents — everyone edits this
templates/     starting point for your recipe
```

## Ground rules

- Add your own recipe. Do not edit anyone else's.
- One pull request per person.
- Real recipes only — something you have actually made.
- Keep it appropriate for a class assignment.
